## About the project

The landing page introduces the world of Soulscapes, presents its story and accessibility features, and guides visitors directly to the playable demo. Its visual direction combines watercolor artwork with a nostalgic desktop-inspired interface that complements the atmosphere of the game.

> The current game demo is designed for desktop computers and requires a keyboard.

## Highlights

- Hero section with a clear path to the playable demo
- Story, atmosphere, and game-feature presentation
- Sensory accessibility information
- Responsive layout for different screen sizes
- Watercolor-inspired art direction
- Metadata prepared for search engines and social sharing
- Direct connection to the Soulscapes game experience

## Run locally

### Requirements

- Node.js 22.13 or newer
- npm

### Installation

```bash
git clone https://github.com/Lime4idan/soulscapes-landing-page.git
cd soulscapes-landing-page
npm install
npm run dev
```

Open the local address shown in the terminal, normally `http://localhost:3000`.

### Production build

```bash
npm run build
npm start
```
